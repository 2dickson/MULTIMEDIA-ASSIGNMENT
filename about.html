ABOUT THE
PROJECT.

An interactive educational website designed to demonstrate digital audio file formats, compression techniques, browser compatibility and audio playback.

PROJECT INFORMATION

Multimedia Audio Lab

01 / OBJECTIVES

Project Objectives

Demonstrate ten digital audio formats using interactive HTML5 audio players and explain the differences between uncompressed, lossless and lossy audio.

02 / IMPLEMENTATION

Technologies Used

HTML5 provides the website structure, CSS3 controls the responsive design, and JavaScript dynamically generates the audio format players.

03 / COMPARISON

Audio Experiment

A one-minute WAV and MP3 comparison demonstrates the relationship between compression, file size and audio quality.

TECHNICAL LEARNING

Key Learning Outcomes

Audio Compression

Understanding how lossy and lossless compression methods affect storage, transmission and sound reproduction.

Browser Compatibility

Understanding why some audio formats cannot be played directly in browsers and how alternative listening previews can improve accessibility.

Web Development

Applying HTML, CSS and JavaScript to build a functional, responsive multimedia website.

IMPORTANT TECHNICAL NOTE

AIFF and WMA files may not be supported by Chrome's native HTML5 audio player. MP3 listening previews are provided, while the original files remain available for download and testing.
