Objectives

Demonstrate audio embedding in HTML5, identify ten common audio file formats, compare compression methods, and document browser compatibility.

Notes

Some codecs, such as WMA and AIFF, are not consistently supported by web browsers. A download link is provided for each format, and playback should be tested in a compatible application where necessary.
