# Multimedia Audio Lab
Four-page educational multimedia website: Home, Formats, Comparison, About.

## Run
Open `index.html` in a browser or publish the files using GitHub Pages.

## Audio
Includes ten actual audio files (WAV, MP3, OGG, FLAC, AAC, M4A, OPUS, AIFF, WMA, WebM) and two 60-second comparison files (WAV and MP3). All are generated test tones. Playback support for some formats depends on the browser; use the download link with a compatible player if needed.

## Before submission
Check your lecturer's exact requirements. Add your student details and replace synthesized demonstration audio if the assignment requires spoken content or real recordings.
